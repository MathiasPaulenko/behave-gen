# $project_name

A Behave BDD project generated by [behave-gen](https://github.com/behave-gen/behave-gen).

## Quickstart

```bash
pip install -e .
behave --dry-run
behave
```

## Layout

```
features/          Gherkin .feature files
features/steps/    Step definitions
environment.py     Behave hooks (before/after scenario, etc.)
behave.toml        Behave configuration
pyproject.toml     Project metadata and behave-gen config
```

## Adding content

```bash
behave-gen add feature login
behave-gen add steps --lib http
behave-gen check
```
