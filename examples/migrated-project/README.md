# migrated-project

A Behave BDD project generated by [behave-gen](https://github.com/MathiasPaulenko/behave-gen).

## Quickstart

The migrated `.feature` files live in `migrated/` (the original Cucumber
directory tree is preserved). Java step definitions are not converted, so you
must add Python step definitions before the scenarios can run:

```bash
pip install -e .
cd migrated
# Add one or more step libraries to implement the migrated scenarios
behave-gen add steps --lib http
behave-gen add steps --lib auth
behave --dry-run
behave
```

## Layout

```
migrated/features/src/test/resources/features/  Migrated Gherkin .feature files
migrated/features/steps/                        Python step definitions (add after migration)
environment.py                                  Behave hooks (before/after scenario, etc.)
behave.toml                                     Behave configuration
pyproject.toml                                  Project metadata and behave-gen config
```

## Adding content

```bash
cd migrated
behave-gen add feature login
behave-gen add steps --lib http
behave-gen check
```
