# openapi-project

A Behave BDD project generated by [behave-gen](https://github.com/MathiasPaulenko/behave-gen).

## Quickstart

The generated project lives in `gen/`. Run the tests from that directory:

```bash
pip install -e ..
cd gen
behave --dry-run
behave
```

## Layout

```
gen/features/          Gherkin .feature files generated from the spec
gen/features/steps/    Generated HTTP step definitions
environment.py         Behave hooks (before/after scenario, etc.)
behave.toml            Behave configuration
pyproject.toml         Project metadata and behave-gen config
spec.yaml              Source OpenAPI 3.0 spec
```

## Adding content

```bash
cd gen
behave-gen add feature login
behave-gen add steps --lib http
behave-gen check
```
